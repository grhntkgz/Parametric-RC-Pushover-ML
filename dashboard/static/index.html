SAP2000 Model Generator

Reinforced concrete model generation, preliminary checks, and pushover control panel

Column sections

Code/pre-screening: For RC columns, a minimum dimension around 30 cm is treated as the lower limit; this software rejects columns below 30 cm. For shear walls, TBDY defines l_w/t_w >= 6, and typical wall web thickness should not be less than story height/16 or 250 mm. Common practice: 40x40-50x50 cm columns for 4-5 stories, 50x50-70x70 cm for 6-8 stories; shear walls often use 25-30 cm thickness and about 1.5-4.0 m length.

Beam sections

Code/pre-screening: Minimum beam width is 25 cm and minimum depth is 50 cm; an L/h <= 15 pre-check is also applied. Common sections: 25x50, 30x50, 30x60, 35x60, 35x70 cm.

Slab parameters

This generator models beam-supported slab panels as horizontal shell areas at every story and bay. Rigid diaphragm assignment is preserved. Code/pre-screening: TBDY 2018 Section 7.11 requires slabs to transfer seismic forces safely to vertical resisting members; TS 500 conditions are used for slab thickness. The TBDY 7.11.3 in-plane elastic diaphragm stress check is a placeholder at this stage; this rigid-diaphragm preliminary model is not a final slab design. Common practice: 0.15-0.20 m in residential/office buildings, and 0.20-0.25 m for longer spans.

Shear wall dimension note

Code/pre-screening: According to TBDY 2018, an RC shear wall is a vertical resisting member whose plan length-to-thickness ratio is at least 6, i.e. l_w/t_w >= 6. Wall web thickness should generally not be less than story height/16 or 250 mm; a 1/20 condition may be considered for some laterally restrained wall segments. Common practice in Turkey: 25-30 cm wall thickness and about 1.5-4.0 m wall length in residential/office projects. The generator adds wall panels in both X and Y directions between column grid lines as shell elements.

Shear wall parameters

Column section selection is independent of shear walls. If enabled, columns remain unchanged; additional wall panels are inserted between selected grid lines in both X and Y directions. The wall contributes in-plane inertia/stiffness in the direction of its long edge.

Concrete classes

Code/pre-screening: Low concrete classes are avoided in RC systems under seismic action; this dataset does not use below C25. Common practice in Turkey: C25-C40 in preliminary design, often C30-C35.

Steel classes

Code/pre-screening: Following TBDY and TS 500 practice, the minimum accepted reinforcement steel for seismic RC structural systems is taken as ribbed S420/B420C; this study uses B420C instead of S420. Common practice in Turkey: B420C and B500C; fy is automatically taken as 420 or 500 MPa.

Values in this tab are candidate reinforcement ratios randomly selected during model generation. Acceptance/rejection lower and upper limits are defined in the Checks tab.

Column reinforcement candidate ratios

Candidate pool: For each model, one longitudinal column reinforcement ratio is selected from this list. Common preliminary design candidates are in the 0.010-0.030 range; if the selected value fails the lower/upper limits in Checks, the candidate is rejected.

Beam support top candidate ratios

Candidate pool: One value is selected from this list for beam top reinforcement at support/end regions. Common parametric candidates are 0.005-0.020.

Beam span bottom candidate ratios

Candidate pool: One value is selected from this list for beam bottom reinforcement in span regions. Common candidates are 0.005-0.016.

Shear wall reinforcement candidate ratios

Candidate pool: If shear walls are enabled, one wall web reinforcement ratio is selected from this list. Common parametric candidates are 0.0025-0.0060; acceptance limits are kept in the Foundation/Soil wall settings.

Slab reinforcement candidate ratios

Candidate pool: The selected ratio is used as the same preliminary assumption for both principal slab directions. Code/pre-screening: In TS 500, for S420/S500, one-way slab principal reinforcement ratio is at least 0.0020; in two-way slabs, at least 0.0015 in each direction and at least 0.0035 total. This generator conservatively requires at least 0.0020 in both directions. Common candidates: 0.0020-0.0040.

Raft foundation reinforcement candidate ratios

Candidate pool: Representative total reinforcement ratio for the raft foundation shell area. Code/pre-screening: Final raft reinforcement must be designed using flexure, shear, punching, soil pressure, and settlement checks; this generator uses 0.0020 as a TS 500 slab/foundation preliminary lower level. Common candidates: 0.0020-0.0050.

TBDY soil classes

Code/pre-screening: TBDY represents soil effects using ZA-ZE classes; in this model, soil class is linked to subgrade modulus. Common use: ZC-ZD medium/soft soil scenarios are often used for dataset diversity.

Soil subgrade moduli kN/m3

Code/pre-screening: TBDY soil class does not directly provide subgrade modulus; exact k_s should come from a geotechnical report. The values here are synthetic/parametric assumptions for Winkler springs. Common practice: higher k_s for ZA-ZB stiff soils and lower k_s for ZD-ZE soft soils.

Machine Learning

A direction-based dataset is built from analyzed models. The selected algorithm learns behavior classes, hinge location groups, FEMA capacity status, and numerical structural response targets from pre-analysis design parameters. ML files are kept separate from production artifacts.
