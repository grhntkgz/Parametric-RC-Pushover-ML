# Output Schema

Each successful model can produce:

- model metadata JSON
- metadata CSV summary
- representative SVG preview
- SAP2000 model file
- analysis log
- pushover response indicators
- machine-learning-ready behavior labels

Core response indicators include:

- peak base shear
- roof displacement
- maximum interstory drift ratio
- maximum plastic rotation
- first plastic hinge type
- first plastic hinge story group
- first plastic hinge plan zone
- critical element type
- critical element story group
- critical element plan zone
- critical damage state
- LS-CP and CP-C occurrence flags
