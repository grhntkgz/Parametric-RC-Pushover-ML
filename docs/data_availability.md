# Data Availability

The repository contains source code and a reduced demonstration dataset under `examples/`.

The complete analysis dataset may be too large for direct GitHub storage because it can include thousands of metadata files, preview figures, logs, SAP2000 model files, and intermediate analysis outputs. For manuscript submission, archive the complete dataset separately and link it from the paper and this repository.

Recommended public archive contents:

- full metadata directory
- full preview SVG directory
- selected logs
- trained ML result summaries
- optional selected SAP2000 `.sdb` files

Large generated SAP2000 files are excluded from Git by default.
